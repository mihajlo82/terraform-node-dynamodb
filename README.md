# Node.js CRUD App with DynamoDB Local

## Description
A simple Node.js CRUD application using **AWS DynamoDB Local**.  
Allows adding, listing, updating, and deleting users.

## Requirements
- Node.js v18+
- DynamoDB Local (Java 8+)
- npm

## Installation
1. Clone project
```bash
git clone <repo-url>
cd node-dynamo-crud
npm install
